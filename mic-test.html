Transcription diagnostic

Speakeasy uses the browser's speech recogniser. This page tests it in isolation, so we can tell whether the API is failing for you or whether the app is using it wrongly.

Test 1 — recogniser on its own

Nothing else touches the microphone. If this fails, the problem is your browser or network, not Speakeasy.

Test 2 — recogniser while the mic is already open

Speakeasy holds the microphone for the level meter and the recording. This checks whether that second claim is what breaks it.

Test 3 — continuous mode

Speakeasy needs continuous mode for long answers. Some builds fail only here.

Ready. Run test 1, then say a sentence out loud.
